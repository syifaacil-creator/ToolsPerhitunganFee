ATM REPORT PARSER & FEE CALCULATION TOOLS

Proses file report TXT menjadi tampilan perhitungan fee, lalu download hasilnya sebagai file Excel.

Pada bagian hasil perhitungan, Kolom kuning A dan D bisa disesuaikan nilainya. Kolom jumlah dan subtotal terisi otomatis dari perhitungan data transaksi.

1. Pilih report TXT yang akan di proses

Format nama file: XXX-Report-Harian-LINK-YYMMDD. Parser ini memisahkan semua kode report yang terhitung pada proses settlement (Transaksi Berhasil, Suspect Open, Suspect Urgent Priority).

Belum ada file dipilih

2. Aturan fee

Nilai awal mengikuti skema eksisting. Dapat di ubah di tabel setelah di proses. (Fee Acquirer/Fee Destination)

  • Info Saldo3.625 / 0
  • Tarik Tunai7.125 / 0
  • Transfer Intra (Issuer=Destination)4.625 / 0
  • Transfer Inter (Issuer<>Destination)4.625 / 1.500
  • Payment3.625 / 0

Hasil perhitungan

Upload file lalu klik proses parser.
